# Tests/Corpus/sync/manifest.txt — the Sync PTY corpus.
#
# One entry per line: <name> <rows> <columns> <origin> <stream>
#
#   rows, columns  the PTY size the stream was written for
#   origin         synthetic — Tests/Corpus/sync/generate.py, deterministic
#                  recorded  — Tests/Corpus/sync/record.py, via Scripts/record-pty-corpus.sh
#   stream         the bytes; a name ending in .z is zlib-compressed
#
# Beside each stream, <name>.reads cuts it into the reads a host makes off the
# PTY: the instant each became readable, its length, and whether a would-block
# followed it. Synthetic entries also mark each logical redraw's byte span and
# the instant of each key the user sent, whose echo is the next read. The
# first comment line of each .reads file says what the entry is.
