# Conformance decisions

Core follows DEC STD 070, the VT510 manual and ECMA-48. It follows xterm
instead only where real programs depend on xterm's behaviour, and the row
names them. A function no standard defines, such as XTGETTCAP, takes the
implementation that defined it as its authority. xterm sources are cited at
xterm-411a.
