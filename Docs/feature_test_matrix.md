# Feature test matrix

Generated by `Tests/Snapshots/gen_matrix.py` from `python3 Tools/showcase/showcase.py --probes`. Each demo section / entry is an automated snapshot, a reply check, or both:

- **snapshot** — feed the explicit sequence, or a deterministic capture of the composite demo, through `--snapshot` and compare the rendered PNG against its baseline.
- **snapshot + reply** — run the snapshot and also feed the sequence through `--probe-reply`, matching the terminal's outbound bytes against `expect`.
- **reply** — the feature draws nothing on the grid, so the entry takes no picture and only matches its outbound bytes against `expect`.
- **page render** — the snapshot pins only the page the entry draws. What its title names, such as speech, a sound, a desktop notification or a rate measured over time, is not in one frame and is not asserted here.

**What a row asserts.** A snapshot compares rendered output with its checked-in baseline; it detects change but does not independently prove correctness. A reply fixture separately checks the specified outbound bytes. The [ECMA-35](ecma35_conformance.md) and [ECMA-48](ecma48_conformance.md) references describe dispatch and model behavior, not a substitute behavioral oracle. Graphics, platform effects, and remote synchronization require their own end-to-end tests. This table is a fixture inventory, not a support or conformance score.
