# Style

See [`coding-conventions.md`](coding-conventions.md) for the authoritative
coding-style rules (WebKit C++ guidelines, and the Safe C++ ownership rules of its
§4). The `Scripts/check-acronyms.py` lint (part of `Scripts/check-style.py`)
enforces the WebKit/Cocoa identifier conventions.
