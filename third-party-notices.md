# Third-party notices

Ubiquitty's own files are licensed under Apache-2.0 (see [`LICENSE`](LICENSE)
and [licensing](Docs/licensing.md)). That does not replace the licenses of the
components below.
Ubiquitty bundles or, for
the optional QUIC transport, fetches the third-party components below. Each keeps
its own license. This file is organized by **distribution surface** — the binary
or artifact a given component actually reaches — so redistributors know exactly
which notices must travel with which download.

> Engineering compliance record, not legal advice. The dependency inventory in
> [`Docs/third-party-inventory.json`](Docs/third-party-inventory.json) is the
> machine-readable source of truth; `Scripts/check-licenses.py` keeps the two in
> sync and fails CI on a dependency that lacks an inventory row or a notice.
> Fetched components (QUIC stack, Sparkle, AppImage tooling) keep a reference
> copy of their license under [`Docs/third-party-licenses/`](Docs/third-party-licenses/);
> the release packaging bundles each one into the artifact that carries it.

## Regenerating + checking

`Docs/third-party-inventory.json` is the machine-readable inventory (source URL,
pinned revision, license expression, distribution surface, notice path per
dependency). `Scripts/check-licenses.py` enforces, with no network access:

- every inventory row needs a matching notice here, and every notice row maps
  back to an inventory entry (bidirectional coverage);
- every discovered third-party input — `Source/ThirdParty/*/`, `Resources/fonts/*.ttf`,
  the `Scripts/fetch-*.sh` pinned tags, `Source/Core/Unicode/*.tables.inc`,
  `Source/Core/Themes/builtin-themes.toml` — has an inventory row (anti-drift);
- every font the macOS bundle, the iOS bundle, the web stage, and the AppImage
  copy out of `Resources/fonts/` is on that package's surface in its row, read
  from the CMake list or script that does the copying;
- `--release` additionally fails on a redistributed row whose `pinnedRev` names
  no version (a dotted number, a dated release tag, or a commit of seven or
  more hex digits) or sits on a moving branch, unless the row's
  `pinNotApplicable` says why no single release applies, and on a
  `redistributionRisk` that blocks the current surface (a copyleft backend
  statically linked into a redistributed binary).

To add a dependency: add its row to `Docs/third-party-inventory.json`, add the
matching notice above under its distribution surface, vendor its license text,
then run `Scripts/check-licenses.py`. It is wired into `Scripts/check-style.py`
and CI.
